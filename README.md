# AI Operating System

Build the complete production-quality website for LIEN PHAT AI now. Do not stop at a plan or ask for approval. Implement the full experience end-to-end, then run a responsive/accessibility/performance pass and fix obvious issues.

BRAND / COMPANY
LIEN PHAT AI is an AI-powered business infrastructure company combining CRM, AI Voice Agents, Conversation AI, sales automation, marketing automation, websites, funnels, customer communication, lead management, scheduling, reputation management, payments, and business workflows into one connected ecosystem.

PRIMARY POSITIONING
“Launch Your AI-Powered Business Operating System.”

SECONDARY POSITIONING
“Stop Running Your Business Through 15 Different Apps.”

BRAND PROMISE
“One System. One Login. One Team Helping You Scale.”

CORE FRAMEWORK
CAPTURE → NURTURE → CLOSE → RETAIN → SCALE

PRIMARY CUSTOMER RESULT
Help businesses capture more leads, respond faster, automate repetitive work, convert more prospects, and create scalable infrastructure.

OVERALL CREATIVE DIRECTION
This must NOT look like a generic SaaS template. The experience should feel like a combination of an Apple product launch, Netflix browsing, Palantir enterprise software, a premium AI startup, and a high-end technology consulting firm. Cinematic, intelligent, expensive, sophisticated, futuristic, calm, and highly conversion-oriented.

DESIGN SYSTEM
- Use deep matte-black / near-black cinematic sections, periodically interrupted by clean white / warm-white sections for breathing room.
- Strategic gradients: electric violet, royal blue, cyan, subtle indigo, soft white light. Avoid excessive neon.
- Use gradients around AI elements, active states, premium buttons, visual transitions, data paths, and focal points.
- Modern editorial premium typography. Very large headlines with aggressive whitespace. Some headlines should occupy 50–70% of viewport height on large screens.
- Keep body copy short. Use progressive disclosure, small high-impact sections, and strong visual hierarchy.
- Use asymmetrical compositions when appropriate.
- Premium rounded cards selectively; do not round every surface.
- Use subtle grain, glass UI layers, polished borders, depth, reflection, soft shadows, and restrained glow.
- Must feel custom and authored, not assembled from default components.

VISUAL LANGUAGE
DO NOT use generic robot graphics or AI brain stock images. Visualize AI using dynamic product interfaces, CRM dashboards, network diagrams, animated data movement, workflow maps, communication streams, customer profiles, pipelines, animated nodes, glass UI, and intelligent system visualizations. Make visitors feel like they are looking into the operating system of the future.

MOTION / INTERACTION
Use subtle, smooth, premium cinematic scroll animation throughout:
- fade/upward reveals
- blur-to-focus text reveals
- scroll scaling
- parallax
- soft animated particles
- slowly moving gradients
- glowing network lines
- animated data paths
- number count-ups
- gently floating dashboard cards
- magnetic/responsive buttons
- scroll-triggered transformations
- pinned storytelling sections
- horizontal scrolling experiences
- visual zoom transitions
Motion must reinforce storytelling, not distract. Respect prefers-reduced-motion. Use GPU-efficient transform/opacity paths. Reduce heavy particles on mobile. Avoid autoplay video backgrounds.

GLOBAL CONVERSION / UX REQUIREMENTS
- Sticky navigation with one prominent CTA.
- Major sections should each have a logical next action.
- Primary conversions: Start 30-Day Trial; Book AI Strategy Call; Purchase Website Implementation; Apply for AI Growth Implementation.
- Use elegant lead-capture modals/drawers/forms for relevant CTA flows with fields that are easy to edit later.
- Capture first name, last name, email, phone, business/company, and one qualifying field appropriate to the CTA.
- Include clear unchecked consent language placeholders.
- Add polished loading, validation, error, and success states.
- Persist leads to a real backend/database if available, not console-only.
- Capture UTM source/medium/campaign/content/term, referrer, CTA source, and landing page with every submission.
- Add provider-agnostic analytics hooks for page_view, CTA clicks, form opens, form start, submit, success, calculator completion, pricing CTA clicks, and outbound links.
- Add a tasteful sticky mobile CTA.
- Add social-proof placeholder zones near high-friction conversion points, clearly marked for verified content only.
- Never invent customer statistics, testimonials, logos, or case-study outcomes.

MOBILE
Mobile must feel equally premium. Reduce particles/effect density. Stack intelligently. Keep typography large but readable. Use no horizontal overflow except intentional touch-friendly horizontal product carousels. Ensure sticky CTA does not obstruct controls. Tap targets minimum ~44px. Maintain fast load and fluid scrolling.

ACCESSIBILITY / PERFORMANCE
- Semantic HTML and proper heading order.
- Keyboard accessible dialogs, carousels, accordions, calculator, navigation, and forms.
- Visible focus states.
- Sufficient contrast.
- Respect prefers-reduced-motion.
- Lazy-load heavy visuals.
- Prioritize fast first-contentful paint.
- Avoid unnecessary blocking scripts and huge media.
- Use transform/opacity for most motion.
- Avoid sacrificing usability for effects.

ENGINEERING
Use the project’s default full-stack TypeScript stack with Tailwind and shadcn/ui. Keep components modular, maintainable, and editable. Use a real database/backend for lead submissions and attribution if the environment supports it. Build provider-agnostic analytics events so GA4, Meta Pixel, or another platform can be wired later without reworking interactions.

FINAL QUALITY BAR
The final website should make LIEN PHAT AI look capable of supporting companies ranging from local businesses to sophisticated multi-location organizations. It should feel like the visitor is experiencing the future operating system of business rather than reading a conventional software website. Build the experience now, not just a plan.
